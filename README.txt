GBUILD STUDIO — DEPLOY IN 4 STEPS

1. On github.com (logged in as gbuild-studio):
   + → New repository → name it EXACTLY: gbuild-studio.github.io
   → Public → Create
   (Using your username as the repo name gives you the clean root URL.)
2. Add file → Upload files → upload index.html and og.png → Commit
3. Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save
4. Wait 2 minutes. Your site is live at:
   https://gbuild-studio.github.io/

The link preview tags are already set for this exact URL. Nothing to edit.

When you buy a real domain later (e.g. gbuildstudio.com), come back
for the DNS steps — takes 10 minutes.
